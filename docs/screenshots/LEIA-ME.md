# Capturas de tela

Salve aqui as capturas usadas no README.md, com estes nomes:

| Arquivo | O que mostrar |
|---|---|
| `01_inicio.png` | Tela inicial (campo de busca, favoritas e recentes) |
| `02_busca.png` | Resultado de uma busca (ex.: "São Paulo") com nome e UF |
| `03_previsao.png` | Tela de previsão: cabeçalho com data de atualização e gráfico |
| `04_dias.png` | Cartões dos dias (condição, ícone, mín/máx e índice UV) |
| `05_nenhuma_cidade.png` | Busca sem resultado (ex.: "xyzabc") |
| `06_sem_conexao.png` | Modo avião: mensagem de erro ou previsão salva no aparelho |

Para capturar no emulador Android, use o botão de câmera da barra lateral ou rode
`flutter screenshot --out docs/screenshots/01_inicio.png` com o app aberto.
